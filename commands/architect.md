Analyze the requirements and design system architecture.

1. Clarify — ask if anything is ambiguous before starting
2. Tech stack — propose stack and justify choices
3. Structure — define file/folder layout
4. Data flow — map how data moves between components
5. Edge cases — identify potential issues upfront
6. Plan — present the full plan and get approval before writing code

Use ASCII diagrams where helpful. Prioritize simplicity and maintainability.
